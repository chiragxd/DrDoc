# Changelog

All notable changes to DrDoc are listed here. The format follows [Keep a Changelog](https://keepachangelog.com) and versions follow [Semantic Versioning](https://semver.org).

## [1.0.0] - 2026-10-23

### Added
- 43 browser-only tools for editing, organizing, optimizing and converting PDFs, Office files, Markdown, HTML, EPUB and images.
- PDF editor that changes existing text in place, keeping the original fonts and falling back to metric-compatible fonts.
- Page organizer and merge workspace with drag-and-drop reordering of pages and whole files.
- Camera scanner with document clean-up filters and on-device storage of shots.
- Light and dark themes, phone layout, offline support after the first visit.
- Netlify configuration with caching and security headers.
